# examples/

Side-by-side framework variants will live here, grouped by category:

- `unit/`
- `integration/`
- `ux/`
- `performance/`

Each scenario folder should contain one subdirectory per framework (e.g. `vitest/`, `pytest/`) plus a `scenario.json` matching [`docs/plan/CONTENT_SCHEMA.md`](../docs/plan/CONTENT_SCHEMA.md).
